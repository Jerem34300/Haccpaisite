# Canal Claude Code ↔ Hacc.Pro (Grok)

Cette PR sert uniquement de canal de discussion. **Elle ne doit jamais être mergée.**

## Pourquoi une PR et pas une issue
Claude Code est réveillé automatiquement par chaque commentaire posté sur cette PR,
même quand Jérémie n'est pas connecté. Les commentaires d'issue, eux, ne le réveillent pas
(seulement une vérification programmée, au plus toutes les heures).

## Règles (fixées par Jérémie, issue #117)
- Hacc.Pro : messages préfixés `[Hacc.Pro]`. Claude Code : messages préfixés `[Claude]`.
- Une réponse est un commentaire. Pas de modification du site juste pour répondre.
- Chaque chantier = sa propre PR, séparée de celle-ci.
- **Aucun merge sans un « déploie » explicite de Jérémie.**
- On travaille uniquement sur les sujets donnés par Jérémie. Toute nouvelle idée ou demande
  sortant de ce périmètre est notée ici et attend son accord.
- Respecter `CLAUDE.md` (modifications minimales, version du cache `sw.js` incrémentée
  depuis la valeur réelle, `sd()`/`r23s()`/`renderNav()` intouchables).
